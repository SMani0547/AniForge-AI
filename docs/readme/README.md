# README artwork

`hero.svg` is original, code-drawn nautical artwork for AniForge: a copper-sailed skiff, violet moon, stars and ocean lines. It contains no external images, fonts or scripts and is not a model-generated result.

The ship, stars and waves animate once for four seconds, then rest. Reduced-motion preferences disable the animation. Static SVG renderers retain the complete composition; animation support depends on the Markdown viewer. The One Piece reference in the root README is a fan nod, not an affiliation or a claim that the artwork depicts franchise characters.
