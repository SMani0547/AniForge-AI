# Anime homepage direction

October 14, 2026. The public homepage now uses a dark, grid-based layout, a large ANIFORGE wordmark, an original anime artist in the hero, floating scene cards and quieter section transitions. The animation is implemented with CSS: the artwork drifts gently, and below-fold content reveals as it enters the viewport. The hero includes a **Pause motion** control, and the page respects the operating system's reduced-motion preference.

## Reference review

The user supplied `Recording 2026-10-14 101047.mp4`, a 17.37-second, 1908 × 1018 recording of the ArtCraft homepage. Local frame inspection showed a near-black canvas, bright headings, muted body text, thin grid borders, uppercase monospace labels, bold sans-serif type with italic serif accents, floating media around the hero and media-first feature sections. The AniForge update adapts that visual direction with fewer moving elements and its own artwork and copy. No ArtCraft site assets were copied. The recording and extracted review frames are not redistributed in this documentation or the public site.
