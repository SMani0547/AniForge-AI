# Oxanium

Unmodified `Oxanium[wght].ttf` from the [Google Fonts distribution](https://github.com/google/fonts/tree/main/ofl/oxanium), saved as `Oxanium-Variable.ttf` on October 14, 2026. Copyright 2019 The Oxanium Project Authors. Redistribution terms are in [OFL.txt](OFL.txt).

Local hosting avoids third-party font requests. The homepage uses the variable weight range with `font-display: swap`; paragraph text keeps the existing readable system stack. This complements the owner's raster logo and does not claim to be its original typeface.
